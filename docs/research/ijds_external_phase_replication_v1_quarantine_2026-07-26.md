# External Phase V1 — Quarantine Record

Status: **STOPPED; NOT ACTIVE EVIDENCE**

The attempted cross-archive V1 is retained only as an adversarial audit record.
Its runner, tests, and result JSON were removed from the active repository
surface, and no external number appears in the manuscript or supplement.

## Reasons for quarantine

- The evidence JSON was created 17.4 seconds before the document presented as
  its protocol; the run was not predeclared.
- The protocol, runner, module, tests, and evidence had no registered tag,
  receipt, active lineage, or input descriptors.
- Freddie `Training` and `OOS test` are disjoint samples from the same chronology,
  not the ordered fit and calibration blocks the V1 text asserted. Only `OOT` is
  documented as later.
- The runner computed calibration phase geometry but did not evaluate frozen
  target groups, target support, target sets, or target coverage.
- Both external models were logistic regressions; the claimed cross-archive
  score-family diversity was false.
- Prosper's 36-month term is not a reconstructed point-in-time endpoint. Its
  target labels came from an administratively uneven servicing snapshot and
  included unresolved outcomes without sharp bounds.
- Archive, horizon, feature, and model choices followed earlier inspection. Home
  Credit's missing origination date is a defensible reason not to impose a random
  split, but the exclusion was retrospective rather than predeclared.
- The runner contained a personal absolute path and recorded no input hashes,
  feature manifest, taxonomy edges, block endpoints, environment, or use-rights
  receipt.
- Prosper's redistribution and academic-use rights are not established for this
  project; external evidence cannot be promoted while that human blocker remains.

## Conditions for any future V2

A future analysis must be described honestly as a *retrospective cross-archive
calibration illustration*, not a clean replication. It requires a post-inspection
protocol fixed before the V2 run; versioned input hashes and rights; configurable
data roots; truly ordered temporal blocks; a freeze that does not open or score
target data; complete target support, prediction-set, coverage, and unresolved
outcome evaluation; generated tables; and registration in the source registry,
claim ledger, evidence manifest, and numerical synchronization tests before any
paper-facing result.

Even then it would be secondary descriptive evidence and would transfer no
coverage guarantee or portfolio conclusion to the active archive.
