# CRPTO foundations status index

**Status:** non-protected routing index, current through 2026-07-31.

The files in this directory are immutable compatibility snapshots of the
pre-audit CRPTO project. They preserve how the pipeline, model-risk dossier,
publication plan, and literature map were understood at earlier dates. They
are useful for chronology and reproducibility, but they are **not** active IJDS
claim authority, active operational instructions, or evidence that a model,
calibrator, conformal construction, portfolio, or policy is currently
selected.

Every pre-existing file in this directory is listed in
`EXTRACTION_MANIFEST.json`. Do not edit those files merely to modernize their
language. In particular, occurrences of “Venn--Abers champion”, “winner”,
“alpha-safe”, “promoted policy”, “current official”, IFRS 9, fairness,
deployment, or funded-set protection are historical statements about the old
pipeline and support no active IJDS claim.

## Non-promotion rule

Historical terminology is not an instruction to rerun the protected DVC graph
or to restore an earlier claim. The following remain provenance only unless a
new protocol, distinct run tag, clean execution, exact artifact seal, source
registration, and explicit claim promotion all succeed:

- the Venn--Abers champion and its selector;
- pool93, compact-v7, selected-policy, and A1--A40 searches;
- the $170.5K, $184.8K, $223K, 45/45 “alpha-safe”, and external-premium
  narratives;
- latent-PD interval, selected/funded-set validity, Markov certificate,
  fairness, IFRS 9, causal, prospective, deployment, and policy-winner claims.

This index withdraws authority from the historical snapshots without rewriting
or re-hashing them.
